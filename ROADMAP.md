# Roadmap

What's left to make MacDoc better. Everything listed in the README works today.

- **Browser controls without setup.** Controlling a browser tab needs "Allow
  JavaScript from Apple Events" turned on in each browser profile. Look for a
  way to play, pause and skip that doesn't need it.
- **Signed releases.** Publish `MacDoc.app` and the Android app as GitHub
  Releases, with the app signed and notarised so macOS doesn't warn.
- **Website.** A Mac-only product page with the interactive demo.
- **iOS / iPadOS.** The `ios/` companion is unreleased; decide whether to finish
  it for iPad or remove it.
- **App switching on the tablet.** Close or minimise windows from the window
  cards, not just bring them forward.
